Shown in the inspector when the open note has a file behind it that a browser can render — pdf, md, txt.

```jsx
<OpenLink href={"/api/file?id=" + id} title="no text extracted — abra o arquivo para ver">Abrir o PDF</OpenLink>
```

Soft accent bed, no border, and an `↗` appended by the component. It is deliberately quieter than a key Button: the extracted text is still the fast path.
