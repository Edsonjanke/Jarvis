Labels a section, a state, or a block of meta. Use it wherever another system would use a small heading.

```jsx
<Eyebrow>Shortest path</Eyebrow>
<Eyebrow count="(4)">Links</Eyebrow>
```

Never bold it, never enlarge it, never give it a colour other than `--ink-3`. The dash is drawn from `currentColor`, so it follows if you do override the colour.
