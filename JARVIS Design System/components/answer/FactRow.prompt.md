The memory panel. Every fact JARVIS decided to keep is listed with the date it was kept.

```jsx
<FactRow when="2026-07-30" text="Boleto da Jatinox sempre 28 dias, nunca 30." onForget={forget} />
```

Never summarise or group these, and never hide old ones behind a "show more" — the panel exists so nothing stored is invisible.
