Every claim in an answer is backed by one of these. An answer with no chips must say so instead.

```jsx
<Cite type="note" title="Deposit policy" onClick={() => open(id)} />
```

Chips sit in a wrapped row above a hairline rule labelled `Sources`. When the list is empty, render the warning line "No note was cited — treat this as unsourced." in `--warn` rather than an empty row.
