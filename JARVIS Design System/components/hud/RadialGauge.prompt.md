A ring gauge with its percentage inside; for one share-of-a-whole reading per section, not for lists of numbers.

```jsx
<RadialGauge value={62} label="memória" caption={
  <StatList rows={[["contexto ativo", "32,4 GB"], ["longo prazo", "128,7 GB"]]} />
} />
```

Use `Meter` for anything that repeats. The ring is deliberately the only circular readout in a rail.
